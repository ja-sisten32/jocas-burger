# 🍔 Joca Burger

Um site moderno e responsivo para uma hamburgueria artesanal fictícia chamada **Joca Burger**, desenvolvido com foco em experiência visual, navegação simples e apresentação dos produtos.

O projeto conta com páginas de início, cardápio e detalhes dos hambúrgueres, utilizando componentes responsivos do Bootstrap e estilizações personalizadas em CSS.

---

## 🚀 Funcionalidades

- ✅ Página inicial com carousel de banners
- ✅ Cardápio interativo com cards de produtos
- ✅ Página de detalhes dos hambúrgueres
- ✅ Navegação entre páginas
- ✅ Design responsivo
- ✅ Efeitos hover nos cards
- ✅ Formulário para novidades e promoções
- ✅ Animações em CSS
- ✅ Estilização personalizada
- ✅ Uso de IDs para navegação direta entre produtos
- ✅ Contagem regressiva até a meia-noite na página inicial (JavaScript)
- ✅ Cardápio carregado da API tech4produtos (fetch + async/await)
- ✅ Página de detalhes carregada pelo ID do produto

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Google Fonts
- JavaScript (fetch, async/await, manipulação do DOM)
- API tech4produtos (produtos do restaurante `JocasBurger`)

## ⚡ Como Executar

1. Baixe os arquivos do projeto
2. Abra o arquivo:

```bash
PgHome/index.html
```

> O cardápio e os detalhes precisam de internet, pois os produtos vêm da API.

3. Execute no navegador 🌐
